*Living document. Update whenever files are added, moved, or deleted.*

## Directory Tree

```
infinite-context/
  memory/              <- THE BRAIN. One markdown file per fact. Ships empty except .gitkeep.
                          Seeded by tools/init.mjs. Yours, on your disk.
  index/               <- GENERATED by tools/build-index.mjs. Never hand-edit, never commit.
    keywords.json      <- keyword retrieval surface: slug + description only
    embeddings.json    <- semantic vectors, present once the embedder has run
    rules.json         <- the always-on behaviour rules, generated from memory frontmatter
    <type>.md          <- per-type browsable indexes
  hooks/
    pre-turn.mjs       <- THE HOOK. Runs on every prompt. Recall + rules injection.
    check-content.mjs  <- refuses writes that would leak secrets or break the memory contract
    check-stop.mjs     <- end-of-turn checks
    check-session-start.mjs
    write-memory.mjs   <- writes a memory with validation
    hooks.json         <- Claude Code hook registrations (SessionStart, PreToolUse, Stop)
  tools/
    init.mjs           <- ENTRY POINT for a new install: seeds rules, builds the index, verifies
    install-hook.mjs   <- registers the hook in ~/.claude/settings.json, backs up first
    build-index.mjs    <- rebuilds every index from memory/
    build-embeddings.mjs
    embed-server.mjs   <- optional local embedder, 127.0.0.1:8477
    verify.mjs         <- THE GATE. Exits non-zero on any failure.
    reflect.mjs        <- contradiction, duplicate and orphan sweep
    eval-recall.mjs    <- accuracy against a fixed query set
    bench-recall.mjs   <- latency of the real hook, end to end
    analytics.mjs      <- results sheet from every logged call, with alerts
    status.mjs         <- live health screen
    brain-server.mjs   <- multi-machine mode host (undocumented in 0.1.0)
    brain-client.mjs   <- multi-machine mode client
    token.mjs, vault.mjs, connect-machine.mjs, pull-from-server.mjs
                       <- multi-machine mode tooling
    install-sync-task.ps1 <- Windows-only, multi-machine mode, not needed locally
  docs/
    recall.svg         <- the diagram the README embeds
  .project/            <- governance docs (you are here)
  .github/             <- PR template, CODEOWNERS, CLA workflow
  CLAUDE.md            <- project identity, AI entry point
  AGENTS.md            <- for the agent installing it, every step verifiable
  README.md            <- for the human
  brain.json           <- YOUR instance config. Not committed upstream. Created by you.
```

## Entry Points

| Entry Point | Purpose |
|---|---|
| `tools/init.mjs` | First run. Seeds rules, builds the index, verifies. |
| `tools/install-hook.mjs` | Wires Claude Code. Restart the session after. |
| `hooks/pre-turn.mjs` | Runs on every prompt, invoked by Claude Code, never by hand. |
| `tools/verify.mjs` | The gate. Run before every commit. |
| `tools/brain-server.mjs` | Multi-machine host. Not part of local mode. |

## Data Flow

```
You write a memory        memory/<type>_<slug>.md with frontmatter
  -> build-index.mjs      keywords.json, embeddings.json, rules.json, <type>.md
  -> you press enter      Claude Code fires hooks/pre-turn.mjs
  -> the hook             matches the prompt on keyword and meaning, fuses, ranks
  -> injection            rules + up to 5 pointers (slug, description, path)
  -> the agent            opens the files it needs, answers
```

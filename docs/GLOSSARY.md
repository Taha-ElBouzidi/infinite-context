# Glossary

Every term this project uses, defined once. If a word in the README or the code is not here, that
is a bug in this file.

## The pieces

**Brain.** The whole memory: the `memory/` directory, the generated `index/`, and the hook that
reads them. One brain per person or per team. It ships empty.

**Memory.** One markdown file under `memory/`, holding one fact. Named `<type>_<slug>.md`. It has
frontmatter (name, description, type, dates) and a body. The body is for the agent to read; the
description is for the index to find.

**Type.** The first word of a memory's filename, one of `user`, `contact`, `project`, `feedback`,
`reference`. It says what kind of thing the fact is about, drives the per-type index, and must
match the `type:` field, or the memory is silently misfiled.

**Slug.** The filename without `.md`. Letters, digits and underscores. It is the memory's identity:
what recall returns, what a wikilink points at.

**Description.** The one-line `description:` in the frontmatter. **It is the entire retrieval
surface.** Nothing in the body is indexed. Write it in the words a person would type when looking
for the fact, not in the vocabulary of the fact itself.

**Rule.** A memory that also carries a `rule:` line. Its rule text is injected into the agent's
context on every single prompt, before recall, in `rule_order`. Rules are how you tell the agent
how to behave, and because they are memories, they are versioned, diffable and editable like
everything else.

**Wikilink.** `[[slug]]` inside a memory body. Links become edges in the memory graph. A memory
with no links in or out is an orphan and fails the gate, because an unreachable fact is a lost one.

## The machinery

**Index.** Everything under `index/`, generated by `build-index.mjs` from `memory/`. Never edited
by hand, never committed upstream, rebuilt in seconds.

**Keyword channel.** Retrieval by exact and stemmed words, scored by inverse document frequency,
from `index/keywords.json`. Always available. Catches names, codes and anything unusual.

**Meaning channel.** Retrieval by embedding similarity, from `index/embeddings.json`. Catches
paraphrases and other languages that share no word with the memory. Needs the local embedder.

**Fusion.** The two channels' rankings merged into one list, so a memory found by either can
surface. Each result is tagged `[keyword]`, `[meaning]` or `[both]` so you can see which channel
earned it.

**Embedder.** `tools/embed-server.mjs`, a small local HTTP process on `127.0.0.1:8477` that turns
text into a vector using `all-MiniLM-L6-v2`, about 90MB, downloaded once. The hook starts it when it
is not running. It never leaves the machine.

**Hook.** `hooks/pre-turn.mjs`. Claude Code runs it on every prompt. It reads the prompt, queries
both channels, fuses, and injects the result. It has under a second and usually uses a fifth of it.

**Injection.** What the hook adds to the agent's context: the rules, then up to five pointers.
About 1.7k tokens on a mature brain, regardless of how many memories exist.

**Pointer.** One line of injection: the slug, the description, and the path to the file. The agent
opens the file if the description says it should. **Recall never injects memory bodies.**

**Recall.** The whole act of turning a prompt into pointers. Measured by `eval-recall.mjs`.

**recall@5.** For a fixed set of test questions, the share for which the right memory appears in
the top five pointers. The number this project reports.

**The gate.** `tools/verify.mjs`. Parses every tool and hook, checks the index matches `memory/`,
runs the hook end to end and checks the rules arrived, runs reflection. Exits non-zero on any
failure. Every commit passes it.

**Reflection.** `tools/reflect.mjs`. Sweeps for contradictions, duplicates, orphans, mistyped and
stale memories. A memory system rots through silent contradiction, not through missing data.

**brain.json.** Your instance configuration: who you are, which rules are mandatory, which machines
are restricted, your git identity. Never committed upstream. Created by you.

## The modes

**Local mode.** One machine. The hook, the index and the embedder all on it. No server, no network,
no account. What 0.1 documents.

**Multi-machine mode.** One host runs `tools/brain-server.mjs`; other machines reach it over a
private network with scoped tokens. Memories live on the host, recall happens on the host, secrets
are encrypted per machine. Used by the authors across three machines. Not yet documented for
outside use.

**Scoped token.** In multi-machine mode, a credential that lets a machine recall and write memories
but is refused, with a 403, on the credential vault. How a machine you do not fully trust still
gets memory.

# How to set and follow a goal

Most goals fail in two ordinary places: they are too vague to measure, and nobody looks at them again after the first conversation. A goal that survives fixes both of those from the start.

## Make it measurable

Ask only for whatever is missing, in one message: the exact result wanted, stated as an outcome rather than an effort, such as a specific distance run without stopping rather than "run more"; the current number and its unit, plus the target number and unit; a target date; one sentence on why it actually matters to the person, since that is what keeps a goal alive once it gets hard; the concrete weekly action and how much time it takes; and any real limits on money, time, health, or anything else that rules options out.

A goal that cannot actually work, because it asks too much too fast or depends on something outside anyone's control, gets pushed back on, with a version proposed that can work instead. When the numbers involved are unfamiliar, what is realistic is worth checking first; see [[reference_how_to_research_with_sources]].

## Save it

The goal becomes its own memory: the goal itself, the starting number and date, the target number and date, the weekly action, the reason it matters, and how progress will be measured, following [[reference_how_to_save_a_memory]]. Its description uses the person's own words for it, the way they would actually refer to it later. If progress will be logged over time, a small log file next to it, with a date, a value, and a note per entry, works well, and where that log lives gets stated clearly.

## Check in

Whenever the goal comes up again, whenever progress gets logged, or whenever someone asks how it is going: recall the goal memory and its log rather than reporting progress from memory of the conversation alone. Compare the actual position against where a straight line from start to target says it should be by now. Say plainly whether that puts things ahead, on track, or behind, by how much, and what that means for the target date. If a goal has been behind for two check-ins in a row, the right response is one concrete change, to the weekly action, the target, or the date, not encouragement without a change behind it. When the goal itself changes, the memory gets updated with the date and the reason, not left to quietly drift out of date.

## Close it

When the target date arrives, the result, what worked, and what did not get recorded in the goal's memory, and whether there is a next goal worth setting gets asked.
